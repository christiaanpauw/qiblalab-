This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

**qiblalab** is an R package for reproducible analysis of early Islamic mosque orientations and hypothesis testing about qibla (prayer direction) development. It ingests Dan Gibson's Early Islamic Qibla Database from Figshare (DOI: 10.6084/m9.figshare.13570655), applies geodesic and circular-statistical methods, and produces auditable, publication-ready results.

The full specification is in `Qiblalab Package Design.pdf`.

## Status

Design phase only. No source code exists yet. Bootstrap order per the design doc: inspect Figshare data → create data dictionary → build package skeleton.

## Core Invariants

**Neutrality**: The package must not prove or disprove any hypothesis. All candidate destinations are treated symmetrically as hypotheses. Use neutral terminology throughout — observed orientation, theoretical bearing, historical method. Never use language that implies ground truth about destinations.

**Uncertainty is first-class**: Coordinates, dates, azimuths, and classifications all carry uncertainty. Support three computation modes: deterministic, sensitivity, and probabilistic.

**Auditability**: Every data-cleaning decision must be logged. Never silently modify input data or assume ground truth. All analytical decisions must be explicit and reproducible.

**Vocabulary distinction**: `observed_orientation` → `theoretical_bearing` → `historical_method`. Do not conflate these three levels.

## Before Writing Implementation Code

The design doc requires 12 methodological decisions to be documented as ADRs in `docs/decisions/` before implementation. Key open questions include: directional vs. axial interpretation, default geodesic model, angular residual definition, treatment of rebuilt mosques, raw/derived data separation, tolerance policy, and clustering method selection.

## v0.1.0 Minimum Scope

Figshare import → data model → great-circle bearings → tolerance-based hypothesis testing → intermediate-bearing calculation → circular statistics → one clustering method → diagnostic plots → two vignettes → full test coverage.

## Research Safeguards

Implement structured warnings for: small samples, weakly dated mosques, single-mosque dependence, and high sensitivity to uncertainty parameters. These are required features, not optional.
